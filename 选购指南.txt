扫地机器人选购指南

一、先搞清楚你的需求
买扫地机器人之前，先回答三个问题：
1. 家里面积多大？（决定续航和基站需求）
2. 有没有宠物？（决定滚刷类型和避障要求）
3. 预算多少？（决定功能取舍）

二、核心参数怎么看
1. 导航方式：
- 随机碰撞型（300元以下）：路线杂乱，容易漏扫，仅适合小面积临时使用，不推荐。
- 陀螺仪导航（500-1000元）：弓字清扫但精度一般，预算紧张可选。
- 激光LDS导航（1000元以上）：建图精准、路径规划高效，主流推荐。
- 视觉导航（1500元以上）：可识别物体，但对光线有要求。
- 激光+视觉融合（2000元以上）：旗舰配置，避障最聪明。

2. 吸力：
- 1500-2500Pa：日常清扫够用。
- 3000-5000Pa：适合地毯和宠物毛发。
- 5000Pa以上：参数过剩，噪音大，不必盲目追高。

3. 避障能力：
- 机械避障：撞上了才转向，不推荐。
- 红外避障：能减速但识别不了具体物体。
- 3D结构光/AI视觉避障：能识别拖鞋、数据线、宠物粪便，养宠家庭必备。

4. 电池容量：
- 3000mAh以下：适合60平米以下。
- 3200-5200mAh：适合60-120平米。
- 5200mAh以上：适合120平米以上或复式。

5. 尘盒容量：
- 300ml以下：需要每天清理。
- 300-500ml：2-3天清理一次。
- 带自动集尘基站：1-2个月换一次集尘袋。

三、扫拖一体怎么选
1. 拖地方式：
- 平板渗水拖布：去污力弱，不推荐。
- 声波震动拖布：去污中等。
- 旋转加压拖布：去污力最强，首选。

2. 基站功能（按重要性排序）：
- 自动洗拖布：解放双手的核心，预算够必上。
- 拖布抬升：保护地毯，有地毯的家庭必选。
- 热风烘干：防臭防霉，南方潮湿地区强烈建议。
- 自动集尘：对灰尘过敏者友好。
- 自动上下水：无需手动换水，装修预留了水电位可选。

四、不同预算的推荐配置
1. 1000元以内：
- 配置：激光导航 + 2000Pa左右吸力 + 单清扫功能
- 适合：租房、小户型、第一次体验扫地机器人
- 提醒：此价位拖地功能基本是摆设，别抱期待。

2. 1000-2000元：
- 配置：激光导航 + 3000Pa吸力 + 基础拖地
- 适合：80平米以内普通家庭，追求性价比
- 代表功能：分区清扫、虚拟墙、定时任务。

3. 2000-3000元：
- 配置：激光导航 + AI视觉避障 + 旋转拖布
- 适合：有宠物、有孩子、对清洁要求高的家庭
- 此价位是甜点区，功能最全性价比最高。

4. 3000-5000元：
- 配置：全能基站（自动洗拖布+集尘+烘干）
- 适合：追求解放双手的懒人党
- 核心价值：手不沾水、两月不管尘。

5. 5000元以上：
- 配置：旗舰全能基站 + 自动上下水 + AI大模型交互
- 适合：大户型、预算充足、追求极致体验
- 提醒：边际提升有限，量力而行。

五、各品牌特点速览
1. 科沃斯：产品线最全，地宝系列覆盖所有价位，售后网点多。
2. 石头：技术流代表，激光导航和算法强，扫地表现稳定。
3. 追觅：参数激进，吸力大，性价比高，售后不如前两家。
4. 云鲸：拖地起家，自动洗拖布先驱，拖地效果口碑好。
5. 小米/米家：生态联动好，价格亲民，适合小米全家桶用户。
6. 戴森：吸力强劲，但缺少拖地功能且价格高，性价比一般。

六、购买前的五个检查
1. 检查户型适配：家里门槛高度是否超过2厘米，超过需考虑虚拟墙方案。
2. 检查家具底部高度：沙发、床底高度是否大于11厘米，否则机器人进不去。
3. 检查WiFi：确认家里有2.4GHz频段WiFi，5GHz频段机器人不支持。
4. 检查基站位置：预留好基站摆放位置，前方需1米开阔空间。
5. 检查地面类型：大面积长毛地毯、深色地板需要特别留意机型的适配性。

七、购买时机
1. 618、双11大促：旗舰机型折扣最大，历史最低价多出现在这两个节点。
2. 新品发布后1-2个月：老款旗舰降价清仓，是捡漏好时机。
3. 以旧换新：品牌和电商平台常有以旧换新补贴，旧家电也能折价。
4. 直播间：头部主播直播间常有专属赠品（耗材套装）。

八、避坑指南
1. 不要买随机碰撞机型，再便宜也是浪费钱。
2. 不要盲目追求最大吸力参数，日常清扫2500Pa绰绰有余。
3. 不带自动洗拖布的扫拖一体机，拖地功能大概率吃灰。
4. 注意耗材成本，某些小众品牌耗材贵且难买。
5. 关注App体验，App难用的机器人再好的硬件也白搭。
6. 认准官方渠道购买，二手平台翻新机多，售后无保障。
7. 看评价重点看差评和追评，好评可能是刷的，差评说的才是真话。

九、到手后的检查清单
1. 开箱检查配件是否齐全（说明书、充电座、边刷、清洁工具）。
2. 首次充电充满后再使用。
3. 首次建图时全程跟进，检查地图是否完整。
4. 测试悬崖传感器：放在茶几边缘看是否自动停止。
5. 测试回充：手动启动回充，确认能准确回到充电座。
6. 7天无理由期内充分试用，发现问题及时退换。
