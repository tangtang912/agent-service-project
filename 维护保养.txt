扫地机器人维护保养全攻略

一、日常保养（每次使用后）
1. 清空尘盒：每次清扫后取出尘盒，将灰尘倒入垃圾桶。尘盒内的垃圾不要超过"MAX"刻度线。
2. 检查滚刷：查看滚刷是否缠绕毛发，用手撕掉缠绕物，保持滚刷清洁。
3. 检查边刷：边刷容易缠绕头发，每次使用后检查，及时清理。
4. 擦拭传感器：用干布轻擦机器底部悬崖传感器和充电极片，保持清洁。
5. 清空污水箱：扫拖一体机型每次拖地后立即倒掉污水，用清水冲洗污水箱。

二、每周保养
1. 深度清洁滚刷：取下滚刷，用剪刀或附带的清理工具割断缠绕毛发，清水冲洗后晾干装回。
2. 清洁滤网：取出滤网，用气吹或软刷清理表面灰尘。滤网不可水洗（可水洗滤网除外）。
3. 擦拭机身：用微湿软布擦拭机器人表面和底座，去除灰尘污渍。
4. 清洁万向轮：取下万向轮，清理轮轴缠绕的毛发和灰尘。
5. 擦拭激光雷达罩：用柔软干布轻擦顶部激光雷达罩，保证建图精度。
6. 清洁基站底盘：扫拖一体机型每周拆下基站底盘冲洗，防止细菌滋生。

三、每月保养
1. 检查轮子磨损：检查驱动轮轮胎花纹，磨损严重及时更换。
2. 深度清洁充电极片：用酒精棉片擦拭充电座和机器人底部极片，防止氧化导致充电不良。
3. 检查电池状态：观察续航时间是否明显缩短，做好电池健康记录。
4. 清理吸口通道：用软毛刷清理尘盒到滚刷之间的吸尘通道。
5. 检查滤网状态：滤网使用超过2个月，即使清洁后吸力仍不足，果断更换。
6. 水箱除垢：使用自来水的用户，每月用柠檬酸溶液清洗水箱和出水孔一次。

四、季度保养（每3个月）
1. 更换滤网：HEPA滤网使用3个月后过滤效率明显下降，建议直接更换。
2. 更换边刷：边刷毛变形弯曲后更换，保证墙角清扫效果。
3. 检查滚刷轴承：滚刷两端轴承如有异响或卡顿，更换滚刷。
4. 更换拖布：扫拖一体机型拖布使用3个月或出现异味发黑时更换。
5. 全面体检：检查所有传感器灵敏度、吸力表现、回充准确率，发现问题及时处理。

六、电池保养要点
1. 机器人长期不使用时，保持电量在50%-80%之间存放，每2-3个月充一次电。
2. 避免将机器人放置在高温环境（暖气旁、阳光直射），高温加速电池老化。
3. 使用原装充电座充电，避免使用非原装配件。
4. 电池完全放电后再充满（每月一次），有助于校准电量显示。
5. 电池使用2年后续航明显缩短属正常老化，及时更换新电池。

七、水箱和拖布保养
1. 水箱每次用完后倒掉余水并晾干，防止细菌滋生。
2. 每周用清水+少量消毒液浸泡水箱内部10分钟，冲洗干净。
3. 拖布每次使用后取下清洗，晾干后再装回。
4. 拖布发黑、发硬、产生异味时立即更换，不要"将就用"。
5. 使用纯净水拖地可以减少水垢，延长水箱寿命。

八、传感器保养
1. 悬崖传感器：每月用棉签轻轻擦拭传感器表面，防止积灰导致误判。
2. 激光雷达：雷达罩有划痕会严重影响导航，擦拭时用软布轻擦，避免硬物接触。
3. 红外传感器：保持传感器窗口清洁透亮。
4. 摄像头（视觉导航机型）：用镜头布擦拭镜头，防止模糊导致避障失效。
5. 碰撞传感器：检查保险杠回弹是否顺畅，卡顿说明内部积灰。

九、基站保养（扫拖一体机型）
1. 底盘清洁：每两周拆下底盘彻底清洗，重点清洁刮条和滤网。
2. 污水箱除味：每次倒掉污水后，可在污水箱中滴入几滴消毒液。
3. 清水箱清洁：每月用柠檬酸溶液浸泡清洗，去除水垢。
4. 烘干通道：每月检查烘干出风口是否积灰，用吸尘器清理。
5. 基站底部防潮：基站周围保持通风干燥，避免放置在潮湿角落。

十、长期存放指南（出差或搬家）
1. 使用拖地功能的机型：排空清水箱和污水箱，取下拖布洗净晾干。
2. 机器人充满电后长按电源键彻底关机。
3. 充电座断电，用防尘罩遮盖机器人。
4. 存放环境保持干燥、常温（10-30度）。
5. 存放超过2个月，期间充电一次防止电池过放损坏。

十一、延长使用寿命的五个习惯
1. 清扫前收拾地面：收走线缆、袜子、小玩具，机器人少卡机寿命更长。
2. 定期耗材更换：滤网、边刷、滚刷该换就换，耗材将就使用会加速电机老化。
3. 及时清理异物：听到异响立即停机检查，带病工作一小时可能造成永久损坏。
4. 保持干燥：机器人怕水，湿垃圾、积水区域不要让它进入。
5. 原厂配件：更换配件使用原厂或正规第三方，劣质配件可能损坏机器。

十二、常见保养误区
误区1：滤网可以水洗——大部分HEPA滤网水洗后纤维结构破坏，过滤效率归零。
误区2：边刷毛发不用管——边刷缠绕后阻力增大，电机过载缩短寿命。
误区3：尘盒一周清一次——尘盒过满吸力下降，电机高负荷运转。
误区4：拖布用到发黑再换——发黑拖布已经是细菌培养皿，拖地等于全屋涂抹细菌。
误区5：机器人不用休息——连续工作超过2小时，电机过热加速老化。
误区6：清洗机器人用水冲——机器人不防水，水冲会导致主板烧毁。
