扫地机器人常见故障排除指南

一、无法开机
现象：按电源键机器人无任何反应，指示灯不亮。
排查步骤：
1. 检查电池是否有电，将机器人放上充电座充电30分钟后重试；
2. 检查电源键是否被卡住或进水；
3. 检查电池与主板的连接线是否松动（需拆机，建议送修）；
4. 若充电也无反应，可能是主板故障，联系售后维修。

二、无法充电
现象：机器人放上充电座后指示灯不亮，App显示电量不增加。
排查步骤：
1. 检查充电座电源是否接通，插座是否通电；
2. 用干布擦拭充电座极片和机器人底部充电极片，去除氧化层和灰尘；
3. 检查充电座指示灯是否亮起，不亮则充电座故障；
4. 更换插座测试，排除插座问题；
5. 以上都正常仍不充电，可能是电池或充电电路故障，送修处理。

三、清扫时吸力明显下降
现象：地面灰尘扫不干净，尘盒进灰少。
排查步骤：
1. 清空尘盒，检查尘盒是否已满；
2. 检查滤网是否堵塞，拍打清理或更换新滤网；
3. 检查滚刷是否被毛发缠绕，清理缠绕物；
4. 检查吸口通道是否有异物堵塞；
5. 检查滚刷是否磨损过度，磨损严重需更换。

四、滚刷不转
现象：机器人正常行走但滚刷不转动，无法扫起灰尘。
排查步骤：
1. 关闭电源，翻转机器人取下滚刷；
2. 清理滚刷两端和滚刷仓内的缠绕毛发；
3. 检查滚刷是否变形，变形需更换；
4. 重新安装滚刷，确保卡扣到位；
5. 若仍不转，可能是滚刷电机或传动皮带故障，送修处理。

五、边刷不转
现象：边刷停止转动或转动无力。
排查步骤：
1. 取下边刷，清理边刷孔内的缠绕毛发；
2. 检查边刷是否变形断裂，更换新边刷；
3. 检查边刷安装是否到位，用力按压听到"咔"声；
4. 若仍不转，可能是边刷电机故障，联系售后。

六、机器人原地打转
现象：机器人不停原地旋转，无法直线行走。
排查步骤：
1. 检查左右轮子是否都有转动，一个轮子不转则电机故障；
2. 检查轮子是否被线缆缠绕卡死，清理缠绕物；
3. 检查地面是否过于光滑（如打蜡地板），机器人摩擦力不足；
4. 用干布擦拭机器底部悬崖传感器；
5. 若问题持续，可能是轮子电机编码器故障，送修处理。

七、机器人后退或不前进
现象：机器人一启动就后退或停止前进。
排查步骤：
1. 检查前方保险杠是否被卡住无法回弹，用手按压测试；
2. 检查保险杠传感器是否积灰，用气吹清理；
3. 检查前方是否有肉眼可见的障碍物紧贴；
4. 重启机器人；
5. 问题依旧则传感器故障，送修处理。

八、无法连接WiFi
现象：App配网失败，机器人无法连接家庭网络。
排查步骤：
1. 确认家庭WiFi为2.4GHz频段（5GHz不支持）；
2. 确认WiFi密码输入正确；
3. 将机器人靠近路由器重新配网；
4. 路由器关闭"双频合一"功能；
5. 重启路由器和机器人后再试；
6. 检查路由器是否开启了MAC地址过滤。

九、App显示机器人离线
现象：机器人已配网，但App中显示离线无法操控。
排查步骤：
1. 检查家庭WiFi是否正常，其他设备能否上网；
2. 检查路由器是否重启或更换过密码；
3. 将机器人放上充电座（部分机型离线超过一定时间自动休眠）；
4. 重新启动机器人；
5. 若频繁离线，可能是路由器信号弱，考虑加装信号扩展器。

十、地图丢失或错乱
现象：机器人地图混乱，房间边界错误，甚至无法定位。
排查步骤：
1. 检查激光雷达罩是否脏污，用软布擦拭；
2. 检查家中是否有大面积镜面或透明玻璃（激光穿透导致误判）；
3. 删除当前地图，重新建图；
4. 建图时打开所有房门，保持光线充足、地面无杂物；
5. 固件升级到最新版本。

十一、自动回充失败
现象：机器人清扫完找不到充电座，或在充电座附近徘徊无法对接。
排查步骤：
1. 检查充电座是否被移动，周围是否有障碍物遮挡；
2. 检查充电座前方是否有1米以上的开阔空间；
3. 清洁充电座极片和机器人底部极片；
4. 手动把机器人放回充电座充电一次，重新定位；
5. 若频繁失败，删除地图重新建图。

十二、悬崖传感器误报
现象：机器人在平地上突然停止或绕行，提示跌落风险。
排查步骤：
1. 用棉签或气吹清理机器底部所有悬崖传感器；
2. 检查地面是否有深色大面积图案（深色吸收红外导致误判）；
3. 检查传感器是否被胶带或污渍遮挡；
4. 在浅色地毯上测试是否正常；
5. 仍误报则传感器故障，送修处理。

十三、拖地不出水
现象：拖地模式下拖布始终干燥，地面无水痕。
排查步骤：
1. 检查水箱是否装到位，卡扣是否扣紧；
2. 检查水箱内是否有水；
3. 检查出水孔是否被水垢或杂质堵塞，用针头轻捅疏通；
4. 在App中确认出水量档位不是"关"或最低档；
5. 检查拖布是否安装到位（部分机型拖布未装好不出水）；
6. 以上正常仍不出水，可能是水泵故障，送修处理。

十四、拖地水量过大
现象：拖地后地面水痕重，机器人走过留下一片水。
排查步骤：
1. 在App中将出水量调低一档；
2. 检查水箱安装是否过松导致持续渗水；
3. 检查水箱密封圈是否老化变形；
4. 检查拖布是否吸水饱和（拖布过脏吸水能力下降）；
5. 若水量失控，可能是电磁阀故障，送修处理。

十五、基站无法清洗拖布
现象：机器人回基站后拖布不洗或洗不干净。
排查步骤：
1. 检查清水箱是否有水，污水箱是否已满；
2. 检查清洗槽内是否有异物堵塞；
3. 检查基站是否通电；
4. 清洁基站底盘和刮条；
5. 若自清洁功能正常但拖布洗不干净，更换新拖布；
6. 仍无法清洗，可能是基站水泵故障，联系售后。

十六、异常噪音
现象：清扫时发出刺耳的异响。
排查步骤：
1. 立即停止清扫，翻转机器人检查滚刷是否有硬物（钉子、玻璃渣）；
2. 检查边刷是否碰到硬物变形；
3. 检查轮子是否卡入小石子；
4. 检查滚刷两端轴承是否磨损；
5. 清理异物后异响消失即可继续使用；若异响持续，可能轴承或电机损坏。

十七、风机异响或不转
现象：吸尘风机声音异常或完全无吸力。
排查步骤：
1. 检查尘盒是否安装到位；
2. 检查滤网是否安装正确，滤网破损可能进入异物损坏风机叶片；
3. 检查吸口通道是否堵塞；
4. 风机异响持续说明风机轴承或叶片损坏，送修更换风机。

十八、电池续航骤降
现象：原来能扫60分钟，现在只能扫20到30分钟。
排查步骤：
1. 检查是否长期使用强力模式（强力模式耗电约为标准模式的1.5倍）；
2. 将电池完全放电后充满，循环2到3次校准电量显示；
3. 检查环境温度（低于10度电池活性下降属正常）；
4. 使用超过1年半且续航明显缩短，电池老化，需要更换电池。

十九、机器人从楼梯跌落
现象：机器人在台阶边缘没有停下，直接跌落。
排查步骤：
1. 立即检查悬崖传感器是否积灰严重，用棉签彻底清洁；
2. 在平地上测试：把机器人搬到茶几边沿看是否会停；
3. 传感器清洁后仍不识别落差，传感器故障需送修；
4. 修复前不要在有落差的楼层使用。

二十、App地图编辑功能异常
现象：无法划区、虚拟墙设置失败、地图编辑按钮灰色。
排查步骤：
1. 确认机器人固件和App都是最新版本；
2. 检查地图是否完整（建图不完整时编辑功能受限）；
3. 重新建图后再尝试编辑；
4. 重启App和机器人；
5. 部分低端机型不支持地图编辑，查看产品规格确认。

二十一、机器人不执行定时任务
现象：设置好的定时清扫到点不启动。
排查步骤：
1. 检查机器人是否在充电座上（部分机型低电量时不启动定时任务）；
2. 检查App中定时任务是否被关闭或时间设置错误；
3. 检查机器人时间是否与手机同步（网络异常可能导致时间错乱）；
4. 检查勿扰模式是否开启（勿扰时段内不执行任务）；
5. 重新设置定时任务并重启机器人。

二十二、清扫时频繁报错停机
现象：清扫中途频繁提示错误并停止工作。
排查步骤：
1. 查看App错误代码，按代码提示排查；
2. 常见代码含义：E1滚刷缠绕、E2边刷卡死、E3轮子卡住、E4尘盒未装、E5悬崖误报、E6电量异常；
3. 按对应部件清理异物后重试；
4. 若频繁报同一错误且清理无效，该部件传感器或电机故障，送修处理。
